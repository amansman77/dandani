# 단단이 (Dandani)

**매일 아침, 나에게 하고 싶은 한 문장을 되새기는 작은 습관.**

단단이는 감정이 흔들리는 날에도 나에게 필요한 말을 다시 읽고, 되새긴 시간을 기록하는 서비스입니다. 한 문장을 정해 반복하고, 마음이 바뀌면 새로운 문장으로 이어갑니다.

## 현재 서비스

1. **문장 정하기** — 오늘 탭에서 직접 쓰거나 예시 문장으로 시작합니다.
2. **매일 되새기기** — 문장을 다시 읽고 ‘오늘의 문장 되새기기’를 누릅니다. 같은 문장의 같은 날짜 기록은 한 번만 저장됩니다.
3. **기록 돌아보기** — 기록 탭에서 진행 중인 문장과 이전 문장, 문장별 되새긴 일수를 확인합니다. 문장을 바꿔도 이전 기록은 남습니다.
4. **다른 사람의 문장 만나기** — ‘다른 사람들의 아침’에서 문장을 보고 내 문장으로 채택할 수 있습니다.
5. **문장 공유하기** — 이미지 카드, X, 문장·링크 복사를 지원합니다. 카카오톡 공유는 JavaScript 키 설정 시 표시됩니다.

첫 방문에는 사용 방법을 안내합니다. 오늘 화면의 ‘N번째 아침’은 방문 기록과 되새김 기록으로 계산하고, 7개 눈금은 이어서 되새긴 일수를 최대 7일까지 표시합니다.

회원가입 대신 브라우저에 저장한 사용자 ID로 기록을 구분합니다. 다른 브라우저·기기로 기록이 자동 연결되지는 않습니다. 활성 문장은 다른 사용자에게 별명과 함께 커뮤니티 목록으로 제공됩니다.

2026-08-28에 챌린지·Story Feed 중심에서 현재 문장 되새기기 흐름으로 전환했습니다. 이전 서비스와 데이터의 보존 범위는 [레거시 백엔드 인벤토리](docs/adr/0005-legacy-backend-inventory.md)에 정리돼 있습니다.

## 코드 구성

| 경로 | 역할 |
|---|---|
| `frontend/` | React 18, MUI 5, Emotion 기반 화면과 Capacitor iOS·Android 프로젝트 |
| `workers/` | Cloudflare Workers API, D1 SQL 스키마, 정기 보고·인사이트 작업 |
| `automation/ux-check/` | Playwright 모바일 화면 관찰 및 운영 자동화 |
| `docs/` | 아키텍처 결정, 이전 실험·개발 계획 |

프론트엔드는 Cloudflare Pages, API는 Cloudflare Workers를 사용합니다. 핵심 데이터는 D1의 `daily_phrases`, `daily_phrase_logs`, `user_events`에 저장합니다. 방문·문구 이벤트를 수집하고, 운영 보고에서 최근 30일의 유입 → 문장 작성 → 2일 이상 되새김을 집계합니다.

## 개발 시작하기

저장소 루트에서 의존성을 설치합니다. Node.js 버전 선택, 로컬 D1 초기화와 환경 변수 설정은 [개발 가이드](DEVELOPMENT.md)를 따릅니다.

```bash
npm ci
```

로컬 DB와 `frontend/.env.local` 설정을 마친 뒤, 별도 터미널에서 실행합니다.

```bash
# 터미널 1: API (기본 포트 8787)
npm run dev:workers
```

```bash
# 터미널 2: 웹 (기본 포트 3000)
npm run start:frontend
```

`REACT_APP_API_URL`을 생략하면 프론트엔드가 운영 API를 호출합니다. 로컬 개발에서는 `http://localhost:8787`을 지정합니다.
