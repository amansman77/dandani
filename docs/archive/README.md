# 역사 자료 아카이브

이 폴더는 현재 제품 요구사항이 아니라 **과거 의사결정의 배경**을 보존한다. 구현 기준으로
사용하지 말고, 현재 동작은 `../PROJECT_CONTEXT.md`와 실제 import/route 경로에서 확인한다.

## 구성

- `experiments/`: 2025년 챌린지 제품의 리텐션·UX 실험과 결과. `../experiments/README.md`의
  광고 실험 기록이 이 문서들을 근거로 인용한다.

챌린지 시절의 구현 계획(`plans/`)과 카드 HTML 프로토타입(`design-prototypes/`)은 그 코드가 없어져
2026-10-23에 삭제했다. 원문은 Git 이력에 있다.

문서 속 경로, API, 이벤트, 용어는 작성 당시의 스냅샷이며 현재 코드와 다를 수 있다.
