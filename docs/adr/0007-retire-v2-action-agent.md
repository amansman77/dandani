# ADR-0007: AI 에이전트 버전(V2)을 되돌린 이유

## Status

Accepted (2026-07-09 결정, 2026-11-13 사후 기록)

## Context

2026-04-30~05-01에 단단이를 AI 에이전트 형태로 개편했다(V2 "Action Personalization Agent",
ADR-PROD-000~014). 사용자의 감정을 읽고 행동을 만들어 주는 행동 플로우, 캐릭터 장면, 패턴 학습,
개인화 인사, 구글 로그인과 단단이 정체성 수집이 포함됐다.

2026-07-09 `1b4393d`에서 V2 전체를 되돌렸지만, 커밋과 문서에 이유가 남지 않았다. 2026-11-13
제작자가 이유를 직접 확인해 주어 이 문서로 남긴다.

## Decision

V2를 되돌리고 방향을 다시 기획한다. 이유는 **제작자 자신이 쓰지 않게 된 것**이다.

> V2 전환 후 직접 사용해 봤는데, 에이전트가 나를 알아주거나 회복시켜 준다는 느낌이 없어서
> 나조차도 안 쓰게 됐다. 제작자조차 안 쓰는 서비스에 사용자도 없다 보니 방향이 맞지 않다고
> 판단해 개편을 기획했다. — 제작자, 2026-11-13

세 후보(사용자 반응, 운영 부담, 방향성) 중 **방향성 판단**이며, 그 판단의 직접 근거는
제작자 본인의 사용 경험이다.

## 기록으로 확인되는 사실

- V2 사용: `action_flows` 19건, 7명(2026-04-30~06-10). 로그인 세션 5건(05-02~05-07).
- 2026-06-10 이후 V2 사용 기록이 없다.
- 2026-05-02~07-08 V2 커밋 0건. 유지보수 부담으로 접은 것이 아니다.
- 2026-07-09 마지막 V2 작업(`9a2d13f`)을 커밋한 뒤 같은 날 되돌렸다.
  V2 코드는 `archive/v2-action-personalization-agent` 브랜치에 남아 있다.

## Consequences

- 2026-07-09 챌린지 기반 버전으로 돌아갔고, 2026-08-28 문장 되새기기로 전환했다(`a2b2b22`).
- 이후 단단이는 AI가 무언가를 만들어 주는 쪽이 아니라, 사용자가 고른 문장 하나를 매일
  되새기는 가벼운 쪽으로 갔다.
- 남은 V2 테이블(`action_flows`, `action_patterns`, `identity_dandanis`, `user_profiles`,
  `user_sessions`)은 고아 테이블로 ADR-0005가 다룬다.

## 다음 결정에 주는 교훈

- **제작자가 매일 쓰고 싶은가**를 첫 번째 검증으로 둔다. 제작자가 쓰지 않으면 사용자 지표를
  기다릴 필요 없이 방향을 다시 본다.
- 되돌릴 때는 이유를 커밋이나 ADR에 바로 남긴다. 이번에는 넉 달 뒤 기억으로 복원했다.
